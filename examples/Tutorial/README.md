## Tutorial Examples
To run the first example, use the following parameters
```
-e -i examples/Tutorial/demo_cloud.smol -b examples/Tutorial/demo_cloud.owl --punning
-l -i examples/Tutorial/demo1.smol --punning
-l -i examples/Tutorial/demo2.smol -b examples/Tutorial/demo2.owl -p asset=https://www.smolang.org/lab/tutorial# --punning
-e -i examples/Tutorial/demo3.smol -b examples/Tutorial/demo3.owl -p asset=https://www.smolang.org/lab/tutorial# --punning
```
