# Sensitivity Analysis for SMOL Copper Simulation

---


## Overview

This sensitivity analysis uses a **one-at-a-time (OAT) approach**: each parameter is varied individually while keeping all others at baseline values. This reveals which parameters have the strongest influence on copper deposition.

### Methodology

1. **Baseline simulation**: Run with all parameters at default values
2. **Parameter variation**: For each of 5 parameters, run 6 simulations with evenly-spaced values between min and max
3. **Analysis**: Compare total copper deposited across all scenarios
4. **Visualization**: Generate tornado diagram and summary comparison plots

---

## Parameters Analyzed

| Parameter | Baseline | Range | Unit | Geological Significance |
|-----------|----------|-------|------|-------------------------|
| **GEOTHERMAL_GRADIENT** | 30.0 | 20.0 - 40.0 | °C/km | Controls temperature-depth profile; affects vein formation threshold (150°C) |
| **VEIN_SALINITY_THRESHOLD** | 31.0 | 28.0 - 35.0 | wt% NaCl | Salinity required for high-temperature vein precipitation; based on fluid inclusion data |
| **INITIAL_COPPER_PPM** | 100.0 | 50.0 - 200.0 | ppm | Initial dissolved copper budget in basinal brine |
| **BRINE_OXIDATION** | 0.5 | 0.3 - 0.7 | 0-1 scale | Oxidation state controlling copper solubility; must be >0.5 for transport |
| **PRECIP_EFFICIENCY** | 0.7 | 0.5 - 0.9 | fraction | Fraction of dissolved copper that precipitates at redox boundaries |

## Quick Start

### Prerequisites

1. **SMOL interpreter compiled**:
   ```bash
   ./gradlew shadowJar
   ```

2. **Python 3.8+** with pip

### Installation

```bash
cd sediment_hosted_copper/sensitivity_analysis

# Create virtual environment
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate

# Install dependencies
pip install -r requirements.txt
```

### Run Analysis

```bash
# Activate virtual environment
source venv/bin/activate

# Run sensitivity analysis (default: 6 samples per parameter)
python scripts/run_sensitivity.py --samples 6

# Generate visualizations
python scripts/visualize_results.py results/sensitivity_results_TIMESTAMP.csv
```

Replace `TIMESTAMP` with the actual timestamp from the results file created by `run_sensitivity.py`.

## Detailed Usage

### 1. Running Sensitivity Analysis

```bash
python scripts/run_sensitivity.py [OPTIONS]
```

**Options:**
- `--samples N`: Number of samples per parameter (default: 6)
  - More samples = finer resolution but longer runtime
  - Recommended: 3 (quick test), 6 (standard), 10 (detailed)
- `--base-dir PATH`: Base directory containing `sensitivity_analysis/` (default: `../`)

**Example:**
```bash
# Quick test (3 samples per parameter, ~16 runs, ~16 hours)
python scripts/run_sensitivity.py --samples 3

# Standard analysis (6 samples, ~31 runs, ~31 hours)
python scripts/run_sensitivity.py --samples 6

# Detailed analysis (10 samples, ~51 runs, ~51 hours)
python scripts/run_sensitivity.py --samples 10
```

**Recommendation**: Run with `--samples 1` first to verify the setup works before committing to a full analysis.

**Output:**
- CSV file: `results/sensitivity_results_YYYYMMDD_HHMMSS.csv`
- JSON file: `results/sensitivity_results_YYYYMMDD_HHMMSS.json`
- Console: Progress updates and summary statistics

### 2. Generating Visualizations

```bash
python scripts/visualize_results.py <results_csv>
```

**Arguments:**
- `results_csv`: Path to the CSV file generated by `run_sensitivity.py`

**Example:**
```bash
python scripts/visualize_results.py results/sensitivity_results_20251119_120000.csv
```

**Output:**
- `figures/tornado_diagram.png`: Parameter sensitivity ranking
- `figures/summary_comparison.png`: Best/worst case comparison
- Console: Summary statistics table

## Output Files

### Results Files

**`sensitivity_results_TIMESTAMP.csv`**:
Tabular data with one row per simulation:
- `scenario`: Descriptive name (e.g., "GEOTHERMAL_GRADIENT_25.00")
- `parameter`: Parameter being varied (or "baseline")
- `value`: Parameter value (or "baseline")
- `total_copper`: Sum of copper across all units (kg/m³)
- `max_copper`: Peak copper concentration in any single unit (kg/m³)
- `status`: Run status ("success", "error", "parse_failed")
- `elapsed_time`: Execution time (seconds)
- `param_*`: Actual parameter values used in simulation

**`sensitivity_results_TIMESTAMP.json`**:
Same data in JSON format for programmatic access.

### Visualization Files

**`tornado_diagram.png`**:
Horizontal bar chart showing parameter sensitivity:
- **Y-axis**: Parameters ranked by sensitivity (most sensitive at bottom)
- **X-axis**: Total copper deposited (kg/m³)
- **Red bars** (left): Effect of low parameter values (relative to baseline)
- **Green bars** (right): Effect of high parameter values (relative to baseline)
- **Black dashed line**: Baseline value
- **Interpretation**: Wider bars = more sensitive parameter

**`summary_comparison.png`**:
Bar chart comparing baseline vs. best/worst scenarios:
- **Blue bar**: Baseline scenario
- **Red bars**: Worst-case scenarios (minimum copper for each parameter)
- **Green bars**: Best-case scenarios (maximum copper for each parameter)
- **Black dashed line**: Baseline reference
- **Value labels**: Total copper (kg/m³) on each bar
